# ClipboardSync Android Client - Developer Guide

## Project Overview

**ClipboardSync** is a multi-platform cloud clipboard synchronization solution that enables real-time clipboard content sharing across MacOS, Windows, Android, and iOS devices. This repository contains the Android client implementation.

### Key Information
- **Project Name**: ClipboardSync (多端云剪贴板项目)
- **Language**: Kotlin
- **Framework**: Android with Jetpack Compose
- **Package**: `com.siw.clipboardsync`
- **Min SDK**: 24 (Android 7.0)
- **Target SDK**: 35
- **Architecture**: MVVM with Compose UI

## Architecture Notes

### Client Architecture Pattern
All platform clients follow the same modular architecture:
- **Clipboard Monitoring Module**: System clipboard change detection
- **Network Communication Module**: HTTP/WebSocket server communication
- **Data Synchronization Module**: Local-cloud data sync logic
- **Background Service Module**: Maintain app operation in background
- **UI Management Module**: User interface and system tray integration

### Synchronization Flow
**Local → Cloud (Upload)**:
```
Local clipboard change → Client detection → Timestamp deduplication → HTTP API upload → Server storage → WebSocket broadcast
```

**Cloud → Local (Download)**:
```
Server WebSocket push → Client notification → HTTP API fetch → Update local clipboard → Mark to avoid loops
```

### Conflict Avoidance
- Timestamp-based deduplication (1-second window)
- Device ID filtering to prevent self-sync
- Content hash comparison for duplicate detection
- User confirmation for sensitive platforms
